# AGENTS.md

## Style guide

### Capitalization and spelling

Always write the project names exactly as follows:

- **Poincare** — no accent (not "Poincaré", "poincare", or "POINCARE")
- **Jablonski** — capital J (not "jablonski")
- **SimBio** — capital S and capital B (not "Simbio", "simbio", or "SIMBIO")

Use the lowercase forms only where they're literal identifiers, such as package names in code, import statements, or install commands (e.g. `import poincare`, `pip install simbio`).

## Commits and pull requests

Do not add `Co-Authored-By` trailers or other AI attribution lines (such as "Generated with ...") to commit messages or pull request descriptions.
