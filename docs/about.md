# About Dyscolab
Dyscolab is a collaborative project focused on the creation of tools for modeling, simulation, and analysis of dynamical systems. We are open to contributions from anybody interested in improving the project; development is done publicly on [github](https://github.com/dyscolab), and the main form of communication is through the [discussion forums](https://github.com/orgs/dyscolab/discussions) on github or by directly contacting the maintainers.
